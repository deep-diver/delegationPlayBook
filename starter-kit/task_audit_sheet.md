# task_audit_sheet.md — 내 할 일 위임 적합성 채점표

> 사용법: 최근 일주일 동안 내 시간을 가장 많이 갉아먹은 일 10개를 적고 네 가지 기준으로 점수를 매긴다. 다 한꺼번에 맡기려 하지 말고 총점이 가장 높은 1등 업무 딱 하나부터 `PLAYBOOK.md`로 옮긴다.

---

## 1. 점수 매기는 기준 (항목당 1~5점, 만점 20점)

| 채점 항목 | 1점 (내가 직접 할 일) | 3점 (쪼개서 맡길 일) | 5점 (당장 넘길 1순위) |
| :--- | :--- | :--- | :--- |
| **얼마나 자주 하나 (F)** | 일 년에 한두 번 어쩌다 하는 일 | 한 달에 두세 번 돌아오는 일 | 매일 또는 매주 어김없이 돌아오는 일 |
| **기준을 적을 수 있나 (S)** | 사람 눈치·정치적 설득·감각이 전부인 일 | 애매한 구석이 있지만 모범 예시가 있는 일 | 볼 파일이 정해져 있고 분류 기준이 명확한 일 |
| **실수해도 무를 수 있나 (R)** | 버튼 누르는 순간 바로 발송·결제되는 일 | 팀 내부 공유 문서를 고치는 일 | 내 폴더(`drafts/`)나 임시보관함에 초안만 쌓는 일 |
| **빨리 검수할 수 있나 (V)** | 맞는지 보려면 원본 전체를 다 다시 읽어야 함 | 몇 군데만 골라 대조하면 10분 안에 확인됨 | 표와 원본 위치 표시 덕분에 3분 안에 확인 끝남 |

---

## 2. 총점별 행동 요령

- **16 ~ 20점 `[당장 넘길 1순위]`:** 시간을 가장 많이 아껴줄 효자 일감이다. 바로 레시피(SOP)를 적어 `Level 3(초안 작성 후 대기)`로 넘긴다.
- **11 ~ 15점 `[반만 쪼개서 넘기기]`:** 통째로 맡기면 배가 산으로 간다. 앞부분의 '자료 모으기·숫자 뽑기·비교표 만들기'까지만 AI에게 시키고, 판단과 설득은 내가 직접 한다.
- **10점 이하 `[내가 직접 하기]`:** AI에게 설명하고 고쳐 쓰는 시간이 내가 직접 해치우는 시간보다 더 든다. 미련 없이 직접 처리한다.
