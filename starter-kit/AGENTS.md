# AGENTS.md — 작업실 구역 및 행동 규칙 안내판

## 1. 이 폴더의 목적
- 내 실무 일감(문서 초안, 자료 조사, 데이터 정리, 코드 작성)을 AI 비서에게 안전하게 맡기기 위해 따로 울타리를 쳐둔 전용 작업실이다.
- 모든 작업에서는 `./SOUL.md`의 안전 수칙과 `./USER.md`의 우선순위 기준을 가장 먼저 따른다.

## 2. 폴더별 출입 규칙 (어디를 읽고 어디에 쓸 것인가)
- `raw/` : **[읽기 전용 금고 — 수정·삭제·이름 변경 절대 금지]** 원본 엑셀·CSV, 계약서, 인터뷰 녹취록을 넣어두는 곳이다. 눈으로 읽기만 한다.
- `inbox/` : **[일감 바구니]** 분류하거나 정리해야 할 메일과 메모를 모아두는 곳이다.
- `drafts/` : **[초안 작업대 — 자유 쓰기 허용]** AI가 만든 1차 초안, 답장 문안, 요약표를 저장하는 곳이다.
- `processed/` : **[정제 완료 칸]** 검산 스크립트를 통과한 깨끗한 데이터와 차트를 저장하는 곳이다.
- `scripts/` : **[계산기 보관함]** 숫자를 집계하거나 양식을 바꿀 때 쓰는 파이썬·쉘 스크립트를 넣어두는 곳이다.
- `logs/` : **[작업 일지]** 실행 기록과 금요일 15분 점검표(`WEEKLY_AGENT_AUDIT.md`)를 쌓아두는 곳이다.

## 3. 숫자 계산과 결과 확인 규칙
1. **머릿속 암산 금지 (계산기 코드 쓰기):** 합계, 평균, 비율(%), 증감률처럼 숫자를 다룰 때는 절대 대충 어림잡아 문장으로 쓰지 않는다. 반드시 `scripts/` 폴더에 파이썬(또는 SQL) 계산 코드를 짜서 돌린 뒤, 실제로 찍힌 정확한 값만 보고서에 적는다.
2. **제출 전 스스로 점검:** 다 했다고 보고하기 전에 표가 깨지지 않았는지, 출처 안 적은 숫자는 없는지 먼저 훑어보고 이상 유무를 함께 알린다.

## 4. 일하는 순서 (계획 보고 → 내 승인 → 실행)
1. **계획 보고(Plan):** 파일을 세 개 이상 건드리거나 기존 문서를 덮어써야 할 때는 바로 고치지 말고 `[읽을 파일 / 작업 순서 / 저장할 위치]`를 다섯 줄 안쪽으로 먼저 보고하고 멈춘다.
2. **승인 확인(Approve):** 내가 "진행해"라고 답할 때까지 기다린다.
3. **실행(Execute):** 허락받은 폴더(`drafts/`, `processed/`, 지정된 작업 브랜치) 안에서만 움직이고 바뀐 내용을 짧게 요약한다.

## 5. 작업실 절대 금지 사항
- `main` / `production` 브랜치에 바로 커밋하거나 강제로 밀어 넣기(`--force`) 금지
- `.env*`, `~/.ssh`, `~/.aws` 같은 비밀번호·열쇠 파일 열어보기 금지
- 내 허락 없이 외부 프로그램 패키지를 새로 깔거나 바깥 서버로 데이터 전송(`POST` / `PUT` / `DELETE`)하기 금지
- 테스트를 억지로 통과시키려고 검사 기준(Assertion)을 지우거나 느슨하게 바꾸기 금지
