# AGENTS.md — 저장소 작업 에이전트 오픈 표준 명세서

## 1. 워크스페이스 개요
- **목적:** 개인 실무 위임 파이프라인(문서 초안, 리서치 검증, 데이터 정제, 코드·스크립트 실행)을 안전하게 구동하기 위한 격리 작업 공간이다.
- **최우선 상위 원칙:** `./SOUL.md`의 안전 경계선과 `./USER.md`의 우선순위 기준을 모든 작업에 공통 적용한다.

## 2. 디렉토리 맵 및 물리적 권한 경계
- `raw/` : **[읽기 전용 — 수정·삭제·이름 변경 절대 금지]** 원본 CSV, 계약서, 고객 인터뷰 원문, 외부 수집 자료 보관.
- `inbox/` : **[읽기 중심]** 트리아지 및 분류 대기 중인 입력 텍스트 보관.
- `drafts/` : **[자유 쓰기 허용]** 에이전트가 생성한 1차 초안, 답장 문안, 요약 리포트 저장소.
- `processed/` : **[조건부 쓰기 허용]** 검증 스크립트를 통과한 정제 데이터 및 차트 저장소.
- `scripts/` : **[생성·실행 허용]** 데이터 집계, 포맷 변환, 무결성 검증용 재현 스크립트 보관.
- `logs/` : **[추가 허용]** 작업 실행 기록 및 금요일 주간 감사(`WEEKLY_AGENT_AUDIT.md`) 이력 보관.

## 3. 정량 계산 및 검증 표준
1. **언어 모델 암산 금지:** 합계, 평균, 비중(%), 증감률 등 모든 수치 연산은 절대 텍스트 추론으로 계산하지 않는다. 반드시 `scripts/` 하위에 Python(또는 SQL/Shell) 스크립트를 작성해 실행한 실제 표준 출력값만 결과 문서에 인용한다.
2. **완료 전 자가 검증:** 산출물 보고 전 출력 포맷 누락, 깨진 마크다운 표, 출처 미표기 항목이 없는지 스스로 대조하고 통과 여부를 함께 보고한다.

## 4. 표준 작업 흐름 (Plan → Approve → Execute)
1. **Plan:** 3개 이상의 파일을 다루거나 기존 결과물을 덮어써야 하는 작업은 실행 전 `[입력 파일 / 수행 단계 / 예상 산출물 경로]`를 5줄 이내로 먼저 브리핑하고 멈춘다.
2. **Approve:** 인간 위임자의 승인(또는 수정 지시)을 확인한다.
3. **Execute:** 승인된 경로(`drafts/`, `processed/`, 지정된 로컬 피처 브랜치) 안에서만 실행하고 변경 요약을 보고한다.

## 5. 저장소 절대 금지 사항 (Repository Red Lines)
- `main` / `production` 브랜치 직접 커밋 및 `--force` 푸시 금지
- `.env*`, `~/.ssh`, `~/.aws` 등 인증·시크릿 경로 열람 및 로그 출력 금지
- 사용자 사전 승인 없는 외부 패키지 설치 및 외부 엔드포인트 데이터 전송(`POST` / `PUT` / `DELETE`) 금지
- 테스트 통과를 위해 기존 검증 조건(Assertion)을 임의로 삭제하거나 완화하는 행위 금지
